# Federated Learning with Differential Privacy for Clinical NLP
Multi-label ICD-9 classification from clinical notes using federated learning and differential privacy across 10 virtual hospitals. Patient data never leaves the hospital — only model weights are shared.


## Overview
| Component | Description |
|-----------|-------------|
| Data pipeline | MIMIC-III preprocessing, ICD-9 category mapping, federated splits |
| Centralized model | Bio_ClinicalBERT fine-tuned on global training set |
| Federated model | FedAvg simulation across 10 virtual hospitals |
| Federated DP model | FedAvg with Opacus differential privacy (ε = 1, 3, 8) |
| App | Docker-based deployment with React frontend and FastAPI backends |

## Quickstart

### 1. Data
Download MIMIC-III from [PhysioNet](https://physionet.org/content/mimiciii/1.4/) and run the pipeline:

```bash
python src/data/01_merge.py
python src/data/02_clean.py
python src/data/03_transform.py
python src/data/04_filter_icd.py
python src/data/05_split_global.py
python src/data/06_split_hospitals.py
python src/data/07_tokenize.py --model_name emilyalsentzer/Bio_ClinicalBERT --max_length 256
python src/data/00_save_tokenizer.py
```

### 2. Model Training
```bash
# centralized
python src/model/centralized/01_train.py --model_name emilyalsentzer/Bio_ClinicalBERT
python src/model/centralized/02_evaluate.py --model_name emilyalsentzer/Bio_ClinicalBERT

# federated
python src/model/federated/03_run.py --model_name emilyalsentzer/Bio_ClinicalBERT --num_rounds 10

# federated dp
python src/model/federated_dp/03_run_dp.py --model_name emilyalsentzer/Bio_ClinicalBERT --num_rounds 10 --epsilon 8.0
```

### 3. App
```bash
docker build -f src/app/backend/Dockerfile.base -t clinical-nlp-base .
docker compose up --build
```

Open `http://localhost:3000` and log in with hospital ID (0–9) and password.

## Data
MIMIC-III clinical notes (discharge summaries) mapped to 19 ICD-9 categories. Train split distributed IID across 10 virtual hospitals at patient level.

Access requires CITI training and PhysioNet data use agreement.


## Privacy
Differential privacy applied via [Opacus](https://opacus.ai/). Embeddings and first 6 BERT layers frozen for Opacus compatibility. Per-hospital privacy budget tracked at runtime.
