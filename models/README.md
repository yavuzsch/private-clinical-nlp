# Model Training and Evaluation
Trains and evaluates clinical NLP models for ICD-9 category classification using centralized and federated learning approaches.


## Requirements
```bash
pip install torch transformers datasets scikit-learn opacus
```


## Usage
### Centralized Training
Train a model on the full global training set:

```bash
python src/model/centralized/01_train.py --model_name distilbert-base-uncased --max_length 256
python src/model/centralized/01_train.py --model_name bert-base-uncased --max_length 256
python src/model/centralized/01_train.py --model_name emilyalsentzer/Bio_ClinicalBERT --max_length 256
```

Evaluate on the test set:

```bash
python src/model/centralized/02_evaluate.py --model_name distilbert-base-uncased
python src/model/centralized/02_evaluate.py --model_name bert-base-uncased
python src/model/centralized/02_evaluate.py --model_name emilyalsentzer/Bio_ClinicalBERT
```

### Federated Training
Run federated simulation across 10 virtual hospitals:

```bash
python src/model/federated/03_run.py --model_name emilyalsentzer/Bio_ClinicalBERT --num_rounds 10 --num_clients 10 --local_epochs 1 --batch_size 16 --learning_rate 2e-5
```

### Federated DP Training
Run federated simulation with differential privacy:

```bash
python src/model/federated_dp/03_run_dp.py --model_name emilyalsentzer/Bio_ClinicalBERT --num_rounds 10 --num_clients 10 --epsilon 1.0
python src/model/federated_dp/03_run_dp.py --model_name emilyalsentzer/Bio_ClinicalBERT --num_rounds 10 --num_clients 10 --epsilon 3.0
python src/model/federated_dp/03_run_dp.py --model_name emilyalsentzer/Bio_ClinicalBERT --num_rounds 10 --num_clients 10 --epsilon 8.0
```


## Structure
```
private-clinical-nlp/
├── models/  # not included, generated by training scripts
│   ├── centralized/
│   │   └── <model_slug>/
│   │       ├── best_model/
│   │       ├── checkpoints/
│   │       ├── results.json  # best val metrics
│   │       └── test_results.json  # test metrics
│   ├── federated/
│   │   └── <model_slug>/
│   │       ├── best_model/
│   │       └── results.json  # metrics per round
│   └── federated_dp/
│       └── <model_slug>/
│           └── epsilon_<value>/
│               ├── best_model/
│               └── test_results.json
└── src/
    └── model/
        ├── centralized/
        │   ├── 01_train.py
        │   └── 02_evaluate.py
        ├── federated/
        │   ├── 01_client.py
        │   ├── 02_server.py
        │   └── 03_run.py
        └── federated_dp/
            ├── 01_client_dp.py
            ├── 02_server_dp.py
            └── 03_run_dp.py
```
